# 过滤升级

<ItemImage id="filter_upgrade" scale="3"/>

<ItemImage id="filter_upgrade" scale="0.5"/>过滤升级可以过滤工厂中生物生成的物品与流体掉落。

右键点击<ItemImage id="factory_upgrade" scale="0.5"/>升级槽，或在<ItemImage id="heart" scale="0.5"/>工厂核心菜单中左键点击该升级，即可进行配置。

它会保留自身配置，因此你可以将该升级移动到不同的工厂中继续使用同一套设置。
