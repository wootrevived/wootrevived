# Filter Upgrade

<ItemImage id="filter_upgrade" scale="3"/>

The <ItemImage id="filter_upgrade" scale="0.5"/> Filter Upgrade filter the items and fluids drop of mobs in the factory.

Right click the <ItemImage id="factory_upgrade" scale="0.5"/> Upgrade Slot, or Left Click the upgrade in the <ItemImage id="heart" scale="0.5"/> Heart Block menu to configure it.

It also keeps its configuration so you can swap the upgrade from different factories.
