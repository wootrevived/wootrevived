# フィルターアップグレード

<ItemImage id="filter_upgrade" scale="3"/>

<ItemImage id="filter_upgrade" scale="0.5"/>フィルターアップグレードは、ファクトリーでモブから生成されるアイテムと液体のドロップをフィルターします。

<ItemImage id="factory_upgrade" scale="0.5"/>アップグレードスロットを右クリックするか、<ItemImage id="heart" scale="0.5"/>ファクトリーハートのメニュー内でアップグレードを左クリックすると設定できます。

設定はアップグレード自体に保存されるため、別のファクトリーへ移しても同じ設定を使えます。
